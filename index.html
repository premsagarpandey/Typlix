Typlix Typing — Touch Typing Speed Test & Practice Game

Typlix Typing (often searched as Typix, Typlix, or Typelix) is a free, modern touch typing trainer, typing speed test, and developer code game.

Created and engineered by Prem Sagar Pandey, Full Stack Software Engineer.

Core Features

  • 50 Progressive Touch Typing Lessons: Master home row, top row, bottom row, numbers, and symbols with visual finger placement.
  • Precision Timed Speed Tests: Benchmark typing velocity in 15s, 30s, 60s, and 120s modes with real-time Gross WPM, Net WPM, and accuracy.
  • Developer Code Mode: Practice real programming syntax across JavaScript, TypeScript, Python, C++, HTML, Rust, and SQL.
  • Acoustic Feedback: Realistic synthesized mechanical switch audio including Cherry MX Blue, Brown, Red, and Topre.
